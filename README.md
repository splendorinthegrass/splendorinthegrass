Canadian builder. Polymath by accident. 128-year plan.

## What I'm Building

**Yennah** — A structurally truthful voxel solar system.
12 celestial bodies. Real elevation data. Dual-grid
macro/micro architecture. Built to walk through,
not just look at.

**MoXai** — Mixture of eXperiences. A novel KV-cache
memory architecture for local LLMs. Not RAG. Not
fine-tuning. Literal persistent memory implantation
via raw KV cache snapshots. Running fully offline
on user-controlled hardware.

**WedgeZero** — An FPGA-backed NVMe storage wedge
for the forces of good. Invisible layer zero between
OS and storage. Two-stage BRAM/DDR4 cache hierarchy
with host-backed persistence over direct Ethernet.
